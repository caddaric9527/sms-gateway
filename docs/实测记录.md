## 3. 本次修掉的三个真实缺陷

1. **`probe_bridge` 探测失败导致 auto 模式退回 AT 驱动**
   - 现象：`/api/status` 报 `COM7 无 AT 响应`，设备"未连接"。
   - 原因：USB CDC 打开后立即写 PING，第一帧被丢弃（单次成功率约 1/3）。
   - 修复：等 300ms → 清缓冲 → PING 重试 3 次；候选串口改为并行探测（启动 20s → 10s）；
     首次未命中时隔 2 秒再探一次。
2. **号码写法不一致导致会话被拆开**
   - 现象：模块上报 `13300000000`、网页输入 `+8613300000000` → 两条独立会话。
   - 修复：新增 `app/phone.py::normalize_peer()`（收/发两侧统一收敛到 `+86` 形态），
     已带 `+` 国家码的号码不再猜测，短号（10086）与国际号保持原样。

3. **运营商显示为空（界面显示 `—`）**
   - 原因：`LuatosModem.read_status()` 把 `operator` 写死成空串，LuatOS 的 mobile 库也没有
     运营商名称接口，不是"获取失败"而是压根没实现。
   - 修复：新增 `app/operator.py::operator_from_imsi()`，用 IMSI 前 5 位（MCC+MNC）反推：
     46011 → 中国电信。**无需重刷固件**，纯上位机侧改动。
