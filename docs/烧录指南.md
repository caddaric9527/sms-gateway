# Air780EPM 烧录指南（给 NAS 短信网关用）

目标：把 `firmware/main.lua` + 带短信能力的 LuatOS 内核烧进模块，让网关能收发短信。
一次性操作，约 15 分钟。

---

## 0. 开始前必须知道的三件事

1. **固件编号必须选 106 号**。你的卡是**中国电信**（IMSI 46011 / ICCID 898603…）。
   合宙文档明确：Air780EPM 里**明确支持电信卡短信的只有 106 / 109 / 110 / 111 号固件**，
   其中 109/110/111 是 ER2/ER3、iRTU、yhm27xx 专用定制，**本项目用 106 号**。
   选错编号的表现：能收到短信，发出去报失败，或干脆收发都不通。
2. **烧录时要进 BOOT 下载模式**。判断标准只有一个：
   **设备管理器里该设备只剩 1 个串口**。如果还是 3~4 个，就是没进去。
3. **烧录会覆盖出厂自带的 airlink 演示脚本**。想恢复就再烧一次官方 demo
   （<https://gitee.com/openLuat/LuatOS/tree/master/module/Air780EPM/demo>）。

## 1. 准备文件

| 文件 | 从哪拿 |
|---|---|
| **Luatools**（≥ 3.0.15，建议最新） | <https://docs.openluat.com/common/Luatools/> |
| **内核固件 `.soc`** | <https://docs.openluat.com/air780epm/luatos/firmware/780epm_version/> |
| **用户脚本** | 本仓库 `sms-gateway/firmware/main.lua` |

固件选型：

- **首选：V2056 的 106 号**
  - `https://cdn18.luatos.com/files/Air780EPM/LuatOS_Air780EPM/LuatOS-SoC_V2056_Air780EPM/`
  - 理由：V2056 修了「UTF-8 转 UCS2 编码错误导致的短信乱码」，V2054 修了 sms 栈溢出。
  - V2056 的已知问题（UART3 收发死机）与本项目无关——我们走 USB 虚拟串口，不用 UART3。
- **备选：V2054 的 106 号**（想更保守时用）
- 下载下来是一个 zip，**解压后选文件名带 `106` 的那个 `.soc`**。

> 也可以在 Luatools 的「项目管理测试」里直接选「内核固件」，工具会列出在线固件；
> 只要编号能确认是 106 号即可。

## 2. 让模块进入 BOOT 下载模式

**先停掉网关服务**（避免抢占串口）：

```powershell
# 关掉正在跑的服务（端口 8099 的 python 进程）
Get-NetTCPConnection -LocalPort 8099 -State Listen -ErrorAction SilentlyContinue |
  ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

然后选一种情况操作：

### 情况 A：板子上有 BOOT 键（核心板 / 开发板）

- **模块已通电开机** → 按住 `BOOT` 键不放 → **短按一下 `RESET`（或 PWR）** → 松开 BOOT
- **模块还没上电** → 按住 `BOOT` 键不放 → **长按 `PWR` 开机** → 松开 BOOT

### 情况 B：板子上没有 BOOT 键

把模组的 **BOOT 引脚与 VDD_EXT 引脚短接**（BOOT 拉到 1.8V），然后给模块上电或复位，
上电后即可松开。

### 判断是否成功（关键）

打开「设备管理器 → 端口 (COM 和 LPT)」：

| 看到的情况 | 结论 |
|---|---|
| **只剩 1 个串口** | ✅ 已进入 BOOT 下载模式，可以烧录 |
| 还是 3~4 个串口（COM5 / COM6 / COM7 …） | ❌ 没进去，重复上面的操作，直到只剩 1 个 |

要确认也可以让我帮你列一下当前串口。

## 3. Luatools 建工程

1. 打开 Luatools，确认左上角版本 ≥ `3.0.15`
2. 点右上角 **「项目管理测试」**
3. **新建工程**，名字随意（例如 `sms_bridge`）
4. **内核固件（底层 CORE）** → 选中第 1 步下载的 **106 号 `.soc`**
5. **脚本和资源列表** → 点「添加脚本文件」→ 选中 `sms-gateway\firmware\main.lua`
   - 文件名必须保持 `main.lua`
   - 添加后它在列表里应显示在**根目录**（不要放进子文件夹）
6. 勾选 **「添加默认 lib」** ← 必须勾（`sys` / `json` / `uart` 等依赖它）
7. 勾选 **「添加底层」**

界面应该长这样：上面一行是 `.soc`，下面脚本列表里是 `main.lua`，下面有「添加默认 lib」的勾。

---

## 4. 烧录

点 **「下载底层和脚本」**（不要点只下脚本）。

- 进度条走到 100%，日志区出现「下载成功 / burn success」即完成
- 期间不要拔线、不要断电
- Luatools 一般会自动让模块重启；没自动重启就**短按 `RESET`**

若报「无法连接设备 / 找不到 BOOT 口」→ 回到第 2 步重新进 BOOT 模式。

---

## 5. 验证桥接脚本跑起来了

烧完、复位后，设备管理器应恢复成多个串口。然后运行：

```powershell
cd sms-gateway
.venv\Scripts\python.exe scripts\probe_bridge.py
```

期望看到：

```
  ✔ COM7           桥接脚本在线
建议在 .env 中设置：MODEM_PORT=COM7
```

- 记下这个端口号（烧固件后口可能变，**以脚本输出为准**）
- 如果全部显示「无响应」，看 Luatools 的**日志窗口**：
  - 有 `sms_bridge` 相关打印 → 脚本在跑，只是没找对口
  - 出现 `+ERR firmware_missing_sms_lib` → **固件编号选错了，换 106 号重烧**

---

## 6. 接上网关

改 `.env`：

```ini
MODEM_PORT=COM7          # 换成 probe_bridge.py 报出来的口
MODEM_PROTOCOL=luatos
```

启动：

```powershell
MODEM_PORT=auto DB_PATH=./data/sms.db .venv\Scripts\python.exe -m uvicorn app.main:app --port 8099
```

界面状态卡应显示：SIM 就绪、信号百分比、ICCID（898603…）、端口 COMx、协议 luatos。

## 7. 排错表

| 现象 | 原因 / 处理 |
|---|---|
| 设备管理器一直是 3~4 个串口 | 没进 BOOT 模式。确认是**按住 BOOT 的同时**去复位/开机，成功时只剩 1 个口 |
| Luatools 点下载后卡在「等待设备」 | 同上；或换一根能传数据的 USB 线（很多线只供电） |
| 烧完脚本不跑 | 脚本没放在工程根目录；或没勾「添加默认 lib」 |
| `probe_bridge.py` 全无响应 | 端口被网关服务占用，先停服务再探测 |
| 日志出现 `firmware_missing_sms_lib` | 固件不含 sms 库 → 换成 **106 号** |
| 能收不能发 | 电信卡未开通 VoLTE / 是物联网卡（物联网卡通常不支持短信）/ 短信中心未就绪，等 30 秒重试 |
| 中文乱码 | 固件太老（V2054 之前），升级到 V2056 的 106 号 |
| 长短信只收到一半 | 脚本已开 `sms.autoLong(true)`，仍异常就把 `log` 发我 |
| 启动后 1 毫秒报 `E/main Lua VM exit!! reboot in 15000ms`，USB 每 15 秒掉一次 | **main.lua 结尾缺少 `sys.run()`**。LuatOS 靠它驱动 task/定时器主循环，缺了它 main.lua 一跑完 VM 就退出并进入 15 秒重启倒计时。修复见 1.0.4 |
| SIM 是带 PIN 码的卡，网页显示「SIM 未就绪」 | 固件 1.1.1 起支持 `SETPIN` 指令解锁，网关侧配 `SIM_PIN` 即可；低于 1.1.1 的脚本会回 `+ERR unknown:SETPIN`，需要重刷 |

## 附：协议速查

模块 ↔ 网关之间是「文本行 + 单行 JSON」，`\r\n` 结尾：

| 上位机 → 模块 | 模块 → 上位机 |
|---|---|
| `PING` | `+PONG` |
| `STATUS` | `+STATUS {"csq":22,"reg":1,"sim":true,"iccid":"...","imsi":"..."}` |
| `SEND {"id":1,"num":"+8613800138000","txt":"你好"}` | `+SENT {"id":1,"ok":true,"err":""}` |
| `SETPIN {"pin":"1234"}` | `+PIN {"ok":true,"iccid":"8986...","err":""}` |
| `SETPIN {"pin":"1234","disable":true}` | `+PIN {"ok":true,"disable":true}` 永久关闭 PIN |
| — | `+SMS {"num":"10086","txt":"...","ts":1764...}` |
| — | `+HB {...}` 每 30 秒、`+READY {...}` 网络就绪时 |

> `SETPIN` 是**固件 1.1.1** 新增的。PIN 不写在脚本里（脚本会烧到模块上），
> 由网关在运行时下发，脚本被读出来也拿不到 PIN。
