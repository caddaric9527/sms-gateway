# 转发规则

> 本文是 README「转发规则」章节的完整版。界面路径：**转发 → 新建规则**。
> 一条规则 = 匹配条件 + 若干目标，可同时推送到多个通道。

## 匹配方式

| 方式 | 例子 | 说明 |
|---|---|---|
| 所有短信 | — | 全量转发 |
| 内容包含 | `验证码` | 简单关键字，忽略大小写 |
| 正则匹配 | `(验证码\|动态码)[^\d]{0,10}(\d{4,8})` | 提取验证码场景常用 |
| 号码包含 | `1069,95588` | 多个用英文逗号分隔 |

建议给验证码类规则加过滤条件，否则运营商通知会全部推到手机上。

## Webhook 目标

```json
{"type": "webhook", "url": "http://192.168.1.10:5678/webhook/sms", "enabled": true}
```

不填模板时按默认 JSON 发送：

```json
{
  "from": "+8613800138000",
  "text": "【某银行】您的验证码为 394827",
  "timestamp": "2026-11-11T07:09:32+08:00",
  "device": "air780epm",
  "rule": "验证码转发",
  "message_id": 128
}
```

### 自定义模板

支持占位符 `{from}` `{text}` `{time}` `{device}` `{device_id}` `{rule}` `{id}`。
**渲染结果是合法 JSON 就按 `application/json` 发，否则按纯文本发** —— 所以 ntfy、
Bark 这类只要纯文本的服务，模板直接写 `{from}：{text}` 即可。

| 服务 | 模板 |
|---|---|
| n8n / Node-RED / 自建 | `{"from":"{from}","text":"{text}","time":"{time}"}` |
| ntfy（自建或 ntfy.sh） | `{from}：{text}` |
| Bark（iOS） | `{"title":"{from}","body":"{text}","group":"短信"}` |
| 企业微信 / 钉钉群机器人 | `{"msgtype":"text","text":{"content":"【短信】{from}\n{text}"}}` |

模板里的 `"` 和换行**不用自己转义**。短信正文带双引号或换行时
（`你的"验证码"是\n123456`），网关会自动做 JSON 转义再序列化，
不会把 JSON 拼坏退回纯文本。也支持自定义 headers。

## 企业微信群机器人

1. 群聊右上角 → 群机器人 → 添加 → 复制 Webhook 地址
   （形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx`）
2. 转发规则 → 新建，匹配条件选「包含」填 `验证码`
3. 目标填 Webhook：URL 粘上面那串，模板用上表企业微信那一行

**出错时会明确报错**。群机器人失败时 HTTP 状态码**仍然是 200**，
错误只在 body 的 `errcode` 里，网关会解析并记录到转发日志：

| errcode | 含义 | 怎么处理 |
|---|---|---|
| 93000 | key 无效 | Webhook 地址复制错了或机器人被删 |
| 45009 | 频率超限 | 群机器人每分钟最多 20 条，加匹配条件过滤 |
| 40058 | 正文超长 | text 消息上限 2048 字节，模板里少带字段 |

> v1.1.5 之前只判 HTTP 状态码，这三类错误会显示成「发送成功」。
> 详见 [CHANGELOG](../CHANGELOG.md)。

## 邮件目标

先在 **设置 → SMTP** 填服务器、账号、授权码，规则里选「邮件」填收件人即可。
手机自带邮件客户端会直接推送通知，不想装新 App 的话这是最省事的一条路。

主题与正文都支持占位符；主题里的换行会被压成一行，避免 `smtplib` 报错。

## 短信转发目标

把收到的短信用本模块转发到另一个手机号，适合老式设备告警。
多设备场景下会用**收到短信的那台模块**发送，不会串到别的设备。

---

## 排障

转发没生效时按顺序看：

1. 规则是否 `enabled`、匹配条件是否命中
2. 操作日志里的失败原因（Webhook 状态码 / errcode / SMTP 报错）
3. 目标地址在 NAS 上能否直接 `curl` 通（内网地址、防火墙）
4. 用 `MODEM_MOCK=1` 起一个模拟模式，发一条测试短信验证整条链路
