# 配置项参考

> 全部通过环境变量配置，写在项目根目录的 `.env`（从 `.env.example` 复制）。
> 改完执行 `docker compose up -d` 生效。完整注释见 [`.env.example`](../.env.example)。

## 串口与协议

| 变量 | 默认 | 说明 |
|---|---|---|
| `MODEM_PORT` | `auto` | 串口。`auto` 自动发现全部模块；也可填 `/dev/ttyACM0` / `COM7` |
| `MODEM_PORTS` | 空 | 显式指定多个口，逗号分隔。填了就不再自动发现 |
| `MODEM_BAUD` | `115200` | 波特率 |
| `MODEM_PROTOCOL` | `auto` | `auto` 自动探测 / `at` 标准 AT 固件 / `luatos` 模块刷了 `firmware/main.lua` |

> Air780EPM 只有 LuatOS 路线，实际都会落到 `luatos`。`at` 是留给其它模块的兼容项。

## 模拟模式

| 变量 | 默认 | 说明 |
|---|---|---|
| `MODEM_MOCK` | `0` | `1` = 不接硬件也能跑界面和转发，带示例短信 |
| `MODEM_MOCK_COUNT` | `1` | 模拟几台设备，多设备联调用 |

## 短信

| 变量 | 默认 | 说明 |
|---|---|---|
| `SMS_STORAGE` | `SM` | `SM` = SIM 卡 / `ME` = 模块存储。不支持 SM 时自动回退 ME |
| `SIM_PIN` | 空 | SIM 卡 PIN（4~8 位）。卡设了 PIN 就填这里，网关在 SIM 未就绪时自动解锁，需固件 1.1.1+ |
| `KEEP_ON_MODEM` | `0` | `0` = 入库后从 SIM 删除（推荐，避免卡满）/ `1` = 保留 |
| `POLL_INTERVAL` | `20` | 全量扫描间隔（秒）。有新短信 URC 时立即同步，实际延迟约 5 秒 |
| `STATUS_INTERVAL` | `45` | 刷新信号/注册状态的间隔（秒） |
| `LOG_RETENTION_DAYS` | `7` | 操作日志保留天数 |

> ⚠️ PIN 连续输错 3 次 SIM 卡会被锁，只能用 PUK 解。填之前先核对清楚。

## 服务

| 变量 | 默认 | 说明 |
|---|---|---|
| `WEB_PORT` | `8080` | 宿主机映射端口 |
| `AUTH_PASSWORD` | 空 | 访问密码，空 = 不登录（仅限完全可信内网） |
| `SECRET_KEY` | 空 | 会话签名密钥，留空则自动生成并存进数据库 |
| `SITE_TITLE` | `短信网关` | 网页标题 |
| `DEVICE_NAME` | `air780epm` | 转发 payload 里带的设备名；多台时可写位置，如「客厅」 |
| `TZ` | `Asia/Shanghai` | 时区，影响短信时间显示 |

## 构建参数（国内网络）

| 变量 | 默认 | 说明 |
|---|---|---|
| `BASE_IMAGE` | `python:3.12-slim` | 拉不动时换镜像站，如 `docker.m.daocloud.io/library/python:3.12-slim` |
| `PIP_INDEX` | 阿里云 | 首选 pip 源 |
| `PIP_FALLBACK_INDEXES` | 腾讯云 → 官方 | 构建时按 `PIP_INDEX` → 回退列表顺序自动重试，某一家不通不影响构建 |
| `TAG` | `1.1.7` | 生成的镜像 tag |

可选 pip 源：

```
阿里云  https://mirrors.aliyun.com/pypi/simple
腾讯云  https://mirrors.cloud.tencent.com/pypi/simple
清华    https://pypi.tuna.tsinghua.edu.cn/simple
官方    https://pypi.org/simple
```

> 早期 README 里写「走清华 pip 源」，实际默认是阿里云 + 自动回退，以本文为准。
